# PDF Pilot 5U Chrome extension

This Manifest V3 extension provides quick access to the live PDF Pilot 5U tools. It does not duplicate PDF processing or upload files; processing remains inside the website.

## Install locally

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Click **Load unpacked**.
4. Select this `extension` folder.

The extension is not published to the Chrome Web Store yet. Publishing requires the owner's Chrome Web Store developer account and listing review.
